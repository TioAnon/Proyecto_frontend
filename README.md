# EduTracker - Plataforma de Gestión de Actividades Académicas

## 1. Descripción de la Problemática y Solución
Esta aplicación frontend da respuesta a la dificultad de mantener el control sobre las actividades académicas pendientes durante el avance del semestre escolar. 

La solución implementada en la Universidad Andrés Bello permite a los estudiantes organizar tareas, proyectos y evaluaciones en una interfaz centralizada. Proporciona visualización del estado (pendiente, en progreso, completada), alertas de vencimiento cronológico e indicadores de progreso global operando exclusivamente en el entorno del cliente[cite: 2].

## 2. Tecnologías Implementadas
- **HTML5:** Estructura semántica del documento[cite: 2].
- **CSS3:** Personalización visual, modelo de caja y sistema Grid nativo[cite: 2].
- **Bootstrap 5:** Sistema de grillas de apoyo, ventanas modales y utilidades responsivas[cite: 2].
- **JavaScript (ES6+):** Lógica de programación, manipulación dinámica del DOM y simulación de memoria (CRUD)[cite: 2].
- **Git & GitHub:** Control de versiones bajo el protocolo Git Flow[cite: 2].

## 4. Instrucciones de Ejecución
1. Clonar el repositorio localmente.
2. Navegar a la carpeta raíz del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. No se requieren dependencias del lado del servidor (backend) ni bases de datos; la persistencia es simulada mediante arreglos de objetos en JavaScript[cite: 2].
